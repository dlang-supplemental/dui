= Roadmap

App-kit gaps for **dui**. Engine unfinished work lives in link:https://github.com/dlang-supplemental/dew/blob/main/ROADMAP.adoc[dew `ROADMAP.adoc`].

Depends on: link:https://github.com/dlang-supplemental/dew[`dew`]. Slogan: *Dew it!*

== Priority next (shared with dew)

. [*x*] Touch capture / gestures on dew, then gesture layer here
. [*x*] Legacy `rmgui` DUB package **removed** (use `dew` only)
. [*x*] Flesh out **dui** state / rebuild (`DuiApp.bind`, `pointerAndFrame`, hello + unittests)

== Related engine work

dui inherits layout, paint, and touch primitives from dew. Remaining GPU work (Vello glyphs/paths, wgpu mesh embeds, non-Windows window host) still unlocks thicker visuals but is not required for the app-kit surfaces above.

See dew roadmap sections: window host, Vello, wgpu 3D, touch, layout, arenas, adapters, and ship/hygiene.
