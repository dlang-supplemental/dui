= dui

App-kit on top of https://github.com/dlang-supplemental/dew[dew]. Engine slogan: *Dew it!*
endif::[]

== Role split

|===
| Package | Owns

| `dew` | Layout, DSL/markup, paint, Vello/wgpu, **touch/pointer primitives**
| `dui` | `DuiApp`, `State!T`, rebuild-on-dirty, future gestures / navigation
|===

== Quick start

[source,d]
----
import dui;

void main()
{
    State!int n = State!int(0);
    DuiApp app;
    n.bindRebuild(() { app.requestRebuild(); });
    app.init((ref UiBuilder ui) {
        return Button("Go").touchFriendly().onClick(() { n = n.value + 1; });
    }, new SoftwareBackend(640, 400));
    app.frame();
}
----
