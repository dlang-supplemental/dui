= changelog

== 2026-08-29 - Editor, undo, clipboard

* `boundTextArea` for multiline `State!string` editing (Enter / Backspace).
* `UndoStack!T` snapshot undo/redo for mode switches and bulk edits.
* `copyText` / `copyHtml` clipboard helpers (Windows HTML Format + Unicode text).
* Version **0.1.3** (expects dew **0.1.6** surfaces: multiline TextField, Canvas, backgrounds).

== 2026-08-25 - Forms, focus, nav, gestures

* Forms: `boundTextField`, `boundCheckBox`, `formRow`.
* Focus: `focusNext` / `focusFirst` / `activateFocused`.
* Navigation: `NavStack`, `backButton`.
* Gestures: `onGesture` (Tap/Drag/Swipe), `scrollable`.
* `DuiApp.tap` (Down+Up); depends on dew path co-dev / upcoming `~>0.1.4`.
* Version **0.1.2**.

== 2026-08-24 - State rebuild reliability

* `DuiApp.bind` / `pointerAndFrame`; `State.update`; single dirty notify path.
* Hello example taps laid-out button center; asserts click increments + rebuild.
* Unittests cover click → dirty → rebuild.
* Depends on `dew` `~>0.1.3` (VStack hit-testing fix + `DEW_VERSION`). Legacy DUB `rmgui` removed upstream.

== 2026-08-24 - Initial dui

* Barebones `DuiApp` + `State!T` on top of `dew`.
* Hello example; touch-friendly buttons use dew's `touchFriendly` / `TouchCapability`.
